Цифровой помощник **централизованной библиотечной системы Миасса** в мессенджере **MAX**:

## Зачем этот бот

Сеть ЦБС Миасса большая: центральная городская библиотека им. Ю.Н. Либединского, центральная детская и десятки филиалов в городе и сёлах (Тургояк, Смородинка, Сыростан и др.). Читателю часто нужны одни и те же ответы — адрес, телефон, правила выдачи, клубы, афиша.

Бот закрывает эти вопросы **в чате**, без звонка и без поиска по сайту:

| Кому | Что даёт |
|---|---|
| Жителям Миасса и окрестностей | Быстрый адрес ближайшего филиала и телефон |
| Новым читателям | Как записаться (14+ и дети младше 14) |
| Постоянным читателям | Сроки выдачи, читальный зал, клубы |
| Библиотеке | Канал обратной связи и единая витрина справки |

Официальный сайт сети: [miasslib.ru](https://miasslib.ru) · почта: miasslib@miass.gov74.ru · адм. тел.: +7 (3513) 53-81-00

## Что умеет бот

| | Функция | Что получает пользователь |
|---:|---|---|
| 1 | **Филиалы** | Список и точечный поиск: «филиал 9», «Тургояк», «Либединского» → адрес и телефоны |
| 2 | **Справка** | Запись в библиотеку, выдача/возврат, правила читального зала, клубы по возрастам |
| 3 | **Мероприятия** | Ссылка на афишу и выставки на miasslib.ru |
| 4 | **Поиск книги** | По автору или названию в CSV-каталоге; при включённом GigaChat — ответ с опорой на каталог |
| 5 | **Отзыв** | Текст сохраняется у бота; можно продублировать на почту ЦБС |

## Сеть в справочнике бота

В `assets/branches.json` заложены точки ЦБС из технического задания, в том числе:

- **ЦГБ** им. Ю.Н. Либединского — пр. Октября, 9  
- **Центральная детская библиотека** — ул. Лихачева, 25  
- **Филиалы № 1–24** и пункт выдачи в с. Устиново  

Часть филиалов — в городе, часть — в посёлках и сёлах (Озерный, Тургояк, Черновское и др.). Бот отвечает и по номеру филиала, и по топониму.

## Поиск книг

По ТЗ ответы с ИИ должны опираться на справочник **«Список книг»**.

| Режим | Поведение |
|---|---|
| Только CSV | Локальный поиск по автору и названию |
| CSV + GigaChat | Краткая формулировка ответа + список найденных позиций; книги вне каталога не выдумываются |
| Нет ключа GigaChat | Справка и локальный поиск работают как обычно |

Формат файла (разделитель `;`):

```text
№ п/п;Описание издания;автор
```

В репозитории — демо `assets/books_sample.csv`. Полный справочник (до ~300 000 слов) передаёт заказчик и подключается через `BOOKS_CSV_PATH`.

## Архитектура (кратко)

```text
MAX Messenger  ──►  Bot (Python)
                      ├─ Dialog FSM + кнопки
                      ├─ FAQ (правила, клубы, мероприятия)
                      ├─ Справочник филиалов
                      ├─ Каталог книг (CSV) ± GigaChat
                      └─ Storage (отзывы, token_usage)
```

Канал: **MAX** (`platform-api2.max.ru`), TLS с корневым CA Минцифры.

## Быстрый старт

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env

# В .env: токен с business.max.ru → Чат-боты
python -m app.main --mode polling
```

| Режим | Команда | Когда |
|---|---|---|
| Long polling | `python -m app.main --mode polling` | разработка |
| Webhook | `python -m app.main --mode webhook` | прод (`POST /max/webhook`) |

Healthcheck: `GET /health` → `{"status":"ok"}`

### Переменные

| Переменная | Назначение |
|---|---|
| `MAX_BOT_TOKEN` | токен бота MAX |
| `MAX_ROOT_CA_PATH` | CA Минцифры для API MAX |
| `BOOKS_CSV_PATH` | путь к CSV «Список книг» |
| `GIGACHAT_ENABLED` | `true` / `false` |
| `GIGACHAT_CREDENTIALS` | ключ заказчика (Basic) |
